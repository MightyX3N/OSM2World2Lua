OpenStreetMap buildings, in plain Lua

A port of OSM2World's building rules to Lua. Give it a building's outline and its OpenStreetMap tags, and it gives back textured triangles: walls, windows and the right roof. No engine code, so it works in LÖVE, Garry's Mod, Roblox or anything else that runs Lua.

What it does

OpenStreetMap describes buildings with an outline and tags: height, building:levels, roof:shape, roof:height, colours and materials, and separate building:part areas for towers and wings. OSM2World turns that into 3D models with years of rules for every tag. OSM2World2Lua follows those rules one for one, so the same tags give the same buildings, just in Lua.

It is meant for games that build their world from map data while the player moves, so it only does the geometry: you hand it outlines in metres and get triangle lists grouped by material, ready to turn into your engine's meshes.

Use it

Copy the o2w folder (and textures) into your project. Plain Lua finds it with require; engines without require set O2W_REQUIRE to their own loader first.

local o2w = require("o2w")
local out = o2w.collector({ max_verts = 65535 })

o2w.building({
  outer = { 0, 0, 10, 0, 10, 8, 0, 8 },           -- metres, x east, y north
  tags = { building = "house", ["building:levels"] = "2",
           ["roof:shape"] = "gabled", ["roof:colour"] = "red" },
  base = 3.5,                                     -- ground elevation
}, out)

for _, g in ipairs(out:groups()) do
  local tex = o2w.materials[g.material].tex       -- e.g. "roof_default.png"
  -- g.d = { x, y, z, u, v, r, g, b, ... }, three vertices per triangle
end

Buildings with parts

Pass building:part areas in parts. As in OSM2World, the building outline itself is only drawn when it has no parts, or when the parts cover too little of it.

Light

Vertex colours are the material colour times a simple sun and sky light. Pass opts.light(nx, ny, nz) to use your own.

Textures

The textures come from OSM2World's default style, scaled down for games by tools/import_style.py. Most are from ambientCG (CC0); others come from the OSM Wiki Texture Library (public domain). The style's own textures and settings are CC0. The full list is in textures/SOURCES.md.
